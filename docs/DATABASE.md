# Database (PostgreSQL 17, Drizzle ORM)

Schema in `apps/api/src/db/schema/*.ts`. Migrations in `apps/api/drizzle/` generated by
`pnpm db:generate` and **reviewed by hand**. Extensions: `pgcrypto`, `pg_trgm`, `citext`.

Conventions: `uuid` primary keys (`gen_random_uuid()`), `created_at`/`updated_at`
`timestamptz`, soft delete only where retention rules need it (`deleted_at`), money as
`bigint` cents, enums as Postgres enums. Every foreign key is indexed.

Class column: P = Public, I = Internal, PII = Personal, S = Sensitive (see `DATA_HANDLING.md`).

## Database roles

- `app_rw`: used by api/worker. CRUD on app tables, **INSERT only** on `ledger_entries` and `audit_log`.
- `app_migrate`: used only by the migrate task. DDL rights.
- `readonly_support`: optional, views only, with PII columns excluded.

## Indexes worth having from day one

- `musician_profiles (status, districts) GIN`, `(rating_avg DESC)`
- `repertoire_songs USING gin (title gin_trgm_ops)`
- `enquiries (client_user_id, created_at DESC)`, `(status, event_date)`
- `enquiry_matches (profile_id, notified_at DESC)`
- `messages (conversation_id, created_at)`
- `bookings (profile_id, event_starts_at)`, `(status, event_starts_at)`

## Migrations so far

- `0000_init`: enums, users, profiles, services, repertoire, enquiries, matches, quotes,
  bookings, reviews, audit_log (with extensions first).
- `0001_constraints_and_grants`: CHECK constraints on money, ratings and counts; revokes
  UPDATE/DELETE/TRUNCATE on `audit_log` from the app role.
- The migration journal lives in `public.__drizzle_migrations` (the migrate role needs
  `CREATE ON DATABASE` because drizzle runs `CREATE SCHEMA IF NOT EXISTS`).
